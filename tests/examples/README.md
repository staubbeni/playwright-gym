# Reference examples

Complete, passing solutions for every lesson, including page objects in
`pages/`. Try the practice yourself first. When you're stuck, read the
matching example, identify the locator, action, and assertion, and then go
back and write your own version in `tests/solutions/`.

These files are also the course's own test suite:

```bash
npm run check:all -- --examples
```

proves that every practice passes against the normal app and fails when its
planted bug is switched on. Screenshot baselines for lesson 22 are created
locally on the first run and are not committed (they are platform-specific).
