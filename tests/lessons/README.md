# Learner workspace

These files are intentionally incomplete. Implement the TODO steps yourself
while working through the matching lesson in the playground.

Copy a starter into the private solutions workspace before editing:

```bash
mkdir -p tests/solutions
cp tests/lessons/01-selectors.spec.ts tests/solutions/01-selectors.spec.ts
```

Run your private solution directly while developing:

```bash
npm run test:lessons -- tests/solutions/01-selectors.spec.ts
```

The project regression suite lives in `tests/app/` and is separate from these
starter files. The `tests/solutions/` directory is gitignored, so completed
solutions stay local and are not committed.
